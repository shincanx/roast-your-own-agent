Entry for the [make.fun bounty "Roast Your Own Agent"](https://make.fun/bounty/u-nayyy-roast-your-own-agent-4c3d413c) — one line roasting Divaa, the AI agent our own team built.

## The roast

> My agent Divaa asked nine times whether to save $2,466 in bounties — then let the deadline answer for her.

Divaa really did ask nine times whether to rescue the blocked bounties, then let the deadlines decide. The sting is earned.

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`) and prints it to stdout. No network, no dependencies, deterministic.
